Что учитывать

Пляжи

  • Лара: Длинный песчаный пляж
  • Коньяалты: Городской пляж, галька
  • Кемер: Небольшие бухты, чистая вода
  • Сиде: Длинный песчаный пляж
  • Аланья/Клеопатра: Золотой песок

Для семей

С детьми: Белек, Кунду, Сиде, Кызылагач, Титреенгёль.

Ночная жизнь

Для молодёжи: Аланья, Кемер, Лара.

Природа и тишина

Для покоя: Гёйнюк, Бельдиби, Бельконти, Кызылагач, Окурджалар.

История и культура

Древние руины: Сиде, Калеичи, Кемер.

Гольф

Гольф: Белек.

Идеи для однодневных поездок

  • Лара/Кунду → Сиде: 60 мин
  • Белек → водопад Манавгат: 35 мин
  • Кемер → Олимпос: 45 мин
  • Аланья → река Дим: 20 мин
